## 4. مخطط حساب الثقة

```
          درجة الثقة = 50 (الحد الأدنى)
                      │
         ┌────────────┼────────────┐
         │            │            │
         ▼            ▼            ▼
    عدد الكلمات    درجة الخطر   الأساس
    المفتاحية       النسبية     (50%)
    ×5%             ×20%
    (max 30%)       (max 20%)
         │            │            │
         └────────────┼────────────┘
                      │
                      ▼
         ┌──────────────────────────┐
         │ إجمالي الثقة (0-100%)   │
         └──────────────────────────┘

مثال: رسالة بـ 4 كلمات مفتاحية و50 نقطة
     = 50 + (4×5) + (50/100×20)
     = 50 + 20 + 10
     = 80%
```

## 6. مخطط التنبيهات

```
مستوى CRITICAL 🚨
│
├─ Dialog بخلفية حمراء (#FF6B6B)
├─ عنوان: "🚨 خطر حرج - تنبيه طوارئ"
├─ الرسالة: السبب التفصيلي
├─ مربع توصيات: 4 توصيات
├─ أزرار: "فهمت" + "اتصل بجهة موثوقة"
└─ إرسال SMS فوري لكل جهة موثوقة

مستوى HIGH ⚠️
│
├─ Dialog بخلفية برتقالية (#FF9800)
├─ عنوان: "⚠️ خطر عالي"
├─ الرسالة: السبب
├─ مربع نصائح: أول 3 توصيات
├─ زر: "حسناً"
└─ إرسال SMS إذا كان وضع الطوارئ

مستوى MEDIUM 🟡
│
├─ SnackBar أصفر
├─ المدة: 4 ثوانٍ
├─ الرسالة: "⚡ ملاحظة + السبب"
└─ لا إرسال SMS

مستوى LOW ✅
│
└─ لا توجد تنبيهات
```
